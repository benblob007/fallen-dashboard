🛡️ Permission Tiers

Tier 1
Moderator

View all pages. Warn, timeout, adjust XP/Coins/ELO. View member details and audit log.

Tier 2
Admin

Everything in Tier 1, plus: Kick members. Create/manage tournaments. Manage staff settings.

Tier 3
Owner

Full access. Ban members. All admin controls. Cannot be removed by other staff.

❓ How to Get Discord IDs

User ID

  1. Open Discord Settings → Advanced
  2. Enable Developer Mode
  3. Right-click any user → Copy User ID

Role ID

  1. Open Server Settings → Roles
  2. Right-click the role → Copy Role ID
  3. Or use the bot: !roleinfo @RoleName
